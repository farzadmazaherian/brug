# Brug — پل زبان

آموزش موقعیت‌محور هلندی و انگلیسی برای فارسی‌زبانان. کاملاً رایگان: بدون سرور، بدون هزینهٔ میزبانی، فقط با کلید رایگان Google Gemini.

این پوشه یک پروژهٔ کامل و آماده است. لازم نیست کدی بنویسید — فقط باید آن را در گیت‌هاب بگذارید و بگذارید سرورهای رایگان گیت‌هاب برایتان بسازند.

---

## مرحلهٔ ۱ — گرفتن کلید رایگان Gemini

۱. به [aistudio.google.com/apikey](https://aistudio.google.com/apikey) بروید.
۲. با حساب گوگل وارد شوید و روی **Create API key** بزنید.
۳. کلید را جایی امن کپی کنید (چیزی شبیه `AIzaSy...`). بعداً داخل خودِ برنامه وارد می‌شود، نه اینجا.

## مرحلهٔ ۲ — ساخت مخزن در گیت‌هاب

۱. اگر حساب گیت‌هاب ندارید، در [github.com](https://github.com/join) رایگان بسازید.
۲. روی **New repository** بزنید. نامش را مثلاً `brug` بگذارید. **Public** باشد (برای رایگان بودن GitHub Pages لازم است). دکمهٔ **Create repository** را بزنید.

## مرحلهٔ ۳ — بارگذاری این پوشه در مخزن

ساده‌ترین راه، بدون نصب هیچ برنامه‌ای، آپلود مستقیم از مرورگر است:

۱. در صفحهٔ مخزن تازه‌ساخته، روی **uploading an existing file** کلیک کنید.
۲. تمام محتوای این پوشه (همهٔ فایل‌ها و پوشه‌ها، از جمله `.github`) را بکشید و رها کنید.
   - نکته: پوشه‌های `node_modules`، `dist` و `src-tauri/target` وجود ندارند و نباید آپلود شوند (در `.gitignore` هم مستثنا شده‌اند).
۳. پایین صفحه روی **Commit changes** بزنید.

اگر با خط‌فرمان راحت‌ترید:
```bash
cd برای-پوشهٔ-brug
git init
git add .
git commit -m "برنامهٔ Brug"
git branch -M main
git remote add origin https://github.com/USERNAME/brug.git
git push -u origin main
```

## مرحلهٔ ۴ — روشن کردن GitHub Pages (برای نسخهٔ موبایل)

۱. در مخزن، به **Settings → Pages** بروید.
۲. زیر «Build and deployment»، گزینهٔ **Source** را روی **GitHub Actions** بگذارید.

## مرحلهٔ ۵ — اجرای خودکار ساخت

به‌محض push کردن، گیت‌هاب خودش شروع می‌کند. برای دیدن پیشرفت:

۱. به تب **Actions** در مخزن بروید.
۲. یک اجرا به نام «Build Brug» می‌بینید که در حال اجراست (چند دقیقه طول می‌کشد، به‌خصوص بخش ویندوز).

## مرحلهٔ ۶ — گرفتن فایل نصبی ویندوز

۱. وقتی اجرا (workflow run) تمام و سبز شد، رویش کلیک کنید.
۲. پایین صفحه، بخش **Artifacts** را ببینید — فایلی به نام `brug-windows-installer` آنجاست.
۳. آن را دانلود کنید؛ یک zip شامل `.msi` و `.exe` است. هرکدام را اجرا کنید تا Brug روی ویندوز نصب شود.

*(هر بار که به شاخهٔ `main` تغییری push کنید، این فرایند دوباره خودکار اجرا می‌شود و نسخهٔ تازه می‌سازد.)*

## مرحلهٔ ۷ — نصب روی گوشی

۱. آدرس سایت را در **Settings → Pages** پیدا کنید (چیزی شبیه `https://USERNAME.github.io/brug/`).
۲. آن آدرس را در مرورگر گوشی (Chrome در اندروید، Safari در آیفون) باز کنید.
۳. در اندروید: منوی مرورگر → «افزودن به صفحهٔ اصلی» یا «نصب برنامه».
   در آیفون: دکمهٔ اشتراک‌گذاری → «Add to Home Screen».
۴. آیکون Brug روی صفحهٔ اصلی گوشی می‌نشیند و مثل یک اپ مستقل باز می‌شود.

## مرحلهٔ ۸ — اولین اجرا

چه روی ویندوز چه روی گوشی، بار اول از شما کلید Gemini خواسته می‌شود (همان‌که در مرحلهٔ ۱ گرفتید). یک‌بار وارد کنید؛ روی همان دستگاه ذخیره می‌ماند.

## توسعهٔ محلی (اختیاری، برای کسانی که می‌خواهند کد را تغییر دهند)

```bash
npm install
npm run dev          # پیش‌نمایش در مرورگر، روی http://localhost:1420
npm run tauri dev    # پیش‌نمایش به‌صورت برنامهٔ دسکتاپ (نیاز به Rust نصب‌شده دارد)
```

## ساختار پروژه

```
src/App.jsx            کل منطق و رابط برنامه
src/main.jsx           نقطهٔ ورود React
src-tauri/              پیکربندی نسخهٔ دسکتاپ ویندوز
public/manifest.json    تنظیمات نصب PWA روی موبایل
public/sw.js             کارکرد آفلاین
.github/workflows/build.yml   خودکارسازی رایگان گیت‌هاب
```

## دربارهٔ هزینه

- میزبانی، ساخت exe، و نصب موبایل: **صفر ریال**، برای همیشه (سقف رایگان GitHub Actions/Pages برای مخازن عمومی سخاوتمندانه است).
- تنها هزینهٔ احتمالی، اگر مصرف روزانه‌تان از سقف رایگان Gemini بگذرد، است — برای استفادهٔ شخصی معمولاً به آن نمی‌رسید.
